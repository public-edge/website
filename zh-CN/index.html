边界

它选择边缘，但不接管网络。

Public Edge Manager 与应用和 DNS 提供商无关。可选集成只补充证据或发布能力，没有一个是必需的。

Public Edge Manager 负责

  • 候选发现 · 来自 Node、Gateway 与 Service，而非私有清单
  • 按证据排除 · 过期、不可达或未就绪的候选不会被发布
  • 受控故障转移 · 短暂探测失败期间保持最近一次良好
  • 权威 DNS · 委派区域，支持 UDP 与 TCP

它从不配置

  • 路由器、NAT 与 BGP · 由原有运维负责
  • 证书与应用路由 · 由各自控制器负责
  • DNS 提供商凭据 · ExternalDNS 写入 PowerDNS，凭据留在那里
  • 路径证据 · 读取 AdvFab 的 NetworkPathAssessment 资源

安装

证据就绪之前，什么都不会发布。

Chart 默认 enabled: false。只有配置好服务目录、nameserver 回退与就绪证据后，边缘才会被发布。

  1. 复制示例 values，替换所有文档中的地址与域名。
  2. 安装签名的 OCI Chart。
  3. 注册服务，并在最小权限的 CLI Pod 中查看推导出的状态。
CLI 指南 →
install.sh
helm install public-edge-manager \
  oci://ghcr.io/public-edge/charts/public-edge-manager \
  --version 0.8.4 \
  --namespace public-edge-system --create-namespace \
  --values values-production.yaml

# 注册服务，然后查看状态
kubectl -n public-edge-system exec deploy/public-edge-manager-cli -- \
  edgectl service-register app.example.com \
  --service app --class web --probe-path /healthz
kubectl -n public-edge-system exec deploy/public-edge-manager-cli -- \
  edgectl status

开源云产品家族

三份可以组合的合约。

AdvFab 生产路径证据，Public Edge 用它回答 DNS，Among Clusters 让集群互联而不共享密钥。RE8CH Cloud 以托管服务形式运行这三者。

AdvFab

Kubernetes 网络证据控制器。

开源 Public Edge

健康感知的公共入口与权威 DNS。

开源 Among Clusters

面向 BYOC 服务的主权集群互联。

开源 RE8CH Cloud

基于这些项目构建的托管集群网络。

托管

展示能力，保护基础设施。

官网与路线图只包含产品合约、脱敏图示与已评审证据。内部地址、路由表、租户、凭据与原始遥测保留在各自的事实系统中。
